# Creative Search

Use only when the user explicitly asks for creative, standout, greenfield, or direction-sensitive work. Direction-selection protocol, not cosmetic polish. Routine fixes, bug repairs, and design-system/conformance work skip it.

## Machine-checkable contract

```text
creative_search: diverge-prototype-compare-commit
creative_trigger: explicit-creative-standout-greenfield-or-direction-risk
direction_count: three-materially-distinct
direction_distance: thesis-structure-or-behavior-not-cosmetic
prototype_policy: cheapest-representative-artifact
selection_basis: user-value-signature-feasibility-proof
hybrid_policy: no-default-hybrid
signature_move: one-memorable-useful-move
subtraction_move: remove-one-generic-or-diluting-element
blind_audience_read: brief-hidden-perception-test
blind_read_fields: understood-action-memory-mismatch
```

## Search loop

1. State user outcome, constraints, and direction risk. If the request is only correctness, routine maintenance, or conformance, stop this branch; use smallest normal path.
2. Generate exactly three feasible directions that differ in thesis, information structure, or user behavior — not colors, type, spacing, or component skins.
3. Build cheapest judgeable artifact per direction: sketch, one-screen flow, short storyboard, runnable slice, or representative fixture. Same input and viewport where comparison matters.
4. Compare all three against user value, signature, feasibility, and proof; record the chosen direction and why others were rejected. Do not blend by default; a hybrid needs an explicit evidence-backed reason.
5. One signature move that is memorable and useful, then subtract one generic or diluting element. Signature must improve user's task, not add decoration.
6. Blind audience read without brief or intended answer: understood, next action, remembered, mismatch. Resolve every material mismatch before commit; if the read cannot run, mark the gate limited rather than green.

## Direction record

```text
Direction A/B/C:
Thesis, structure, or behavior changed:
Representative artifact:
User value:
Signature opportunity:
Feasibility and proof path:
Rejected or selected:
```

Selected direction re-enters Evidence and Pressure gates. Keep the three artifacts and blind-read notes as comparison evidence; do not certify from a written rationale alone.
