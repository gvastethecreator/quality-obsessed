# Security policy

Quality Obsessed is an instruction package and does not run a network service. Its repository validation scripts operate on local package files and temporary relocation directories.

Report a suspected vulnerability privately through [GitHub security advisories](https://github.com/gvastethecreator/quality-obsessed/security/advisories/new). Do not include secrets, private prompts, customer artifacts, or exploit details in a public issue.

Supported security fixes target the current `main` branch.
